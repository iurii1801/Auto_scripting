# Лабораторная работа №2: Создание Python-скрипта для взаимодействия с API

## Цель работы

Изучить взаимодействие Python-скрипта с Web API: отправка HTTP-запросов, обработка полученных данных, сохранение их в файл и обработка ошибок.

---

## Задание

**В рамках лабораторной работы необходимо:**

1. Создать новый каталог `lab02` и в нём реализовать скрипт `currency_exchange_rate.py`.

2. Скрипт должен выполнять следующие функции:

   - получать курс одной валюты к другой на заданную дату (валюты и дата задаются параметрами командной строки);
   - сохранять результат в JSON-файл, имя которого содержит валюты и дату;
   - сохранять файлы в папку `data`, которую нужно создать, если её нет;
   - обрабатывать ошибки и выводить понятные сообщения (также писать их в файл `error.log`);
   - поддерживать вывод списка доступных валют;
   - корректно работать при разных наборах параметров.

3. Протестировать работу скрипта на диапазоне дат от **2025-01-01 до 2025-09-15** (не менее 5 дат с равными интервалами).

4. Подготовить файл `readme.md`, в котором описать:

   - установку зависимостей;
   - примеры запуска скрипта;
   - описание структуры кода.

---

### Структура проекта

```bash
lab02/
├─ app/                       # код сервиса 
├─ data/                      # результаты (JSON-файлы с курсами)
├─ .env                       # ключ API для сервиса
├─ currency_exchange_rate.py  # основной Python-скрипт
├─ docker-compose.yaml        # запуск сервиса
├─ error.log                  # лог ошибок (создаётся при ошибках)
├─ readme.md                  # сам отчёт
├─ requirements.txt           # зависимости Python
└─ .venv/                     # виртуальное окружение (в git не коммитим)
```

### Краткая структура скрипта (основные функции и логика)

- **Парсинг аргументов** (`argparse`): `FROM`, `TO`, `DATE`, `--url`, `--api-key`, `--list-currencies`.
- **Загрузка API-ключа**: приоритет `--api-key` → `API_KEY` из окружения → `.env`.
- **Валидация даты**: формат `YYYY-MM-DD` + проверка корректности.
- **list_currencies()**: POST `key` + `?currencies` → вывод списка валют.
- **fetch_rate()**: POST `key`, GET `from`, `to`, `date` → получение курса.
- **Логирование ошибок**: в `error.log` (сетевые/HTTP/ошибки API/валидации).
- **Сохранение результатов**: `data/rate_<FROM>_<TO>_<DATE>.json` (UTF-8, с отступами).

## Ход выполнения работы

### Шаг 1. Запуск сервиса через Docker Compose

Перед написанием `Python`-скрипта необходимо поднять локальный сервис, предоставляющий API.
Для этого в каталоге `lab02` выполняется команда:

```bash
docker compose up -d
```

![image](https://i.imgur.com/XRK5HMx.png)

Она загружает необходимые образы, создаёт сеть `lab02_default` и запускает контейнер `php_apache`, который предоставляет API.

### Шаг 2. Проверка доступности API и получение списка валют

После запуска сервиса необходимо убедиться, что API доступен и корректно отвечает на запросы.
Для этого используется утилита `curl`, которая отправляет HTTP-запросы.

Команда:

```bash
curl.exe -X POST -d "key=EXAMPLE_API_KEY" "http://localhost:8080/?currencies"
```

![image](https://i.imgur.com/1CtAzPt.png)

- `-X POST` — указывает метод запроса (POST).
- `-d "key=EXAMPLE_API_KEY"` — передаётся ключ API (в реальном случае он может быть уникальным).
- `http://localhost:8080/?currencies` — URL для получения списка доступных валют.

В ответ API вернул список валют:

```json
{"error":"","data":["MDL","USD","EUR","RON","RUS","UAH"]}
```

Это значит, что сервис работает и готов предоставлять курсы валют.

### Шаг 3. Получение курса валюты на указанную дату

Следующий тест API — запрос курса одной валюты относительно другой на конкретную дату.
Для этого используется команда `curl` с параметрами:

```bash
curl.exe -X POST -d "key=EXAMPLE_API_KEY" "http://localhost:8080/?from=USD&to=MDL&date=2025-01-01"
```

- `from=USD` — исходная валюта (доллар США).
- `to=MDL` — целевая валюта (молдавский лей).
- `date=2025-01-01` — дата, на которую нужно получить курс.

![image](https://i.imgur.com/kx1pmLF.png)

В ответ API вернул данные:

```json
{"error":"","data":{"from":"USD","to":"MDL","rate":0.05411518959256674,"date":"2025-01-01"}}
```

Здесь видно:

- `from` — исходная валюта;
- `to` — целевая валюта;
- `rate` — курс на указанную дату;
- `date` — дата, за которую был получен курс.

### Шаг 6. Запуск скрипта для диапазона дат

По условию лабораторной работы необходимо протестировать скрипт на **нескольких датах с равными интервалами**.
Для этого был выбран период с 2025-01-01 по 2025-09-01 с шагом в два месяца.

В PowerShell использовался цикл:

```powershell
$dates = @('2025-01-01','2025-03-01','2025-05-01','2025-07-01','2025-09-01')
foreach($d in $dates){
  python .\currency_exchange_rate.py USD MDL $d --url http://localhost:8080 --api-key EXAMPLE_API_KEY
}
```

![image](https://i.imgur.com/uHbQZlD.png)

Результат выполнения:

- в папке `data` создано 5 файлов:

```powershell
rate_USD_MDL_2025-01-01.json
rate_USD_MDL_2025-03-01.json
rate_USD_MDL_2025-05-01.json
rate_USD_MDL_2025-07-01.json
rate_USD_MDL_2025-09-01.json
```

- каждый файл содержит курс валюты на соответствующую дату;
- ошибок при выполнении не возникло.

![image](https://i.imgur.com/XBBtsl4.png)
