# Лабораторная работа №1: Написание простого Shell-скрипта для автоматизации задач

## Цель работы

Научиться создавать и выполнять простые Shell-скрипты для автоматизации рутинных задач в операционной системе Linux.

## Задание

### **Автоматизировать одну из следующих задач с помощью Shell-скрипта:**

### 1. Создание резервной копии важного каталога:

- Скрипт должен называться `backup.sh`;
- Скрипт должен принимать два аргумента: путь к каталогу, который нужно скопировать, и путь к каталогу, где сохранить резервную копию;
- Второй аргумент должен быть необязательным и по умолчанию равен каталогу `/backup`;
- Скрипт должен создавать архив `tar.gz` с текущей датой в имени файла;
- Скрипт должен проверять существование указанных каталогов и выводить соответствующие сообщения об ошибках.

### 2. Очистка временных файлов:

- Скрипт должен называться `cleanup.sh`;
- Скрипт должен принимать хотя бы один аргумент: путь к каталогу, который нужно очистить;
- Остальные аргументы являются необязательными и указывают типы файлов для удаления (например, `.tmp`, `.log`);
- По умолчанию удаляются файлы с расширением `.tmp`;
- В конце выполнения скрипта он должен выводить количество удалённых файлов;
- Скрипт должен проверять существование указанного каталога и выводить соответствующие сообщения об ошибках.

### 3. Мониторинг использования дискового пространства каталогом:

- Скрипт должен называться `disk_usage.sh`;
- Скрипт должен принимать два обязательных аргумента: путь к каталогу для мониторинга и максимальный объём (в мегабайтах), выделенный для каталога;
- Третий аргумент — необязательный, он задаёт пороговое значение использования диска в процентах (по умолчанию 80%);
- Если использование диска превышает пороговое значение, скрипт должен отправить уведомление на указанный email;
- Скрипт должен выводить текущее использование диска в процентах для указанного каталога в файл `disk_usage.log`;
- Скрипт должен проверять существование указанного каталога и выводить соответствующие сообщения об ошибках.

### 2. Скрипт backup.sh — резервное копирование каталога

**Условия:** 2 аргумента (исходный каталог; каталог для сохранения — опционально, по умолчанию `/backup`), архив `tar.gz` с датой в имени, проверки существования каталогов и сообщения об ошибках.

Код скрипта:

```sh
#!/usr/bin/env bash
# Использование:
#   ./backup.sh SOURCE_DIR [DEST_DIR=/backup]

SRC="$1"
DEST="${2:-/backup}"

# Проверка аргументов
if [ -z "$SRC" ]; then
  echo "Ошибка: укажите исходный каталог." >&2
  echo "Использование: $0 SOURCE_DIR [DEST_DIR=/backup]"
  exit 1
fi

# Проверки каталогов
if [ ! -d "$SRC" ]; then
  echo "Ошибка: исходный каталог '$SRC' не существует." >&2
  exit 2
fi

if [ ! -d "$DEST" ]; then
  echo "Ошибка: каталог назначения '$DEST' не существует." >&2
  echo "Подсказка: создайте его командой: sudo mkdir -p $DEST && sudo chown \"$USER\":\"$USER\" $DEST"
  exit 3
fi

# Имя архива: <имя_каталога>_YYYY-MM-DD.tar.gz
DATE=$(date +%Y-%m-%d)
BASE=$(basename "$SRC")
ARCHIVE="${BASE}_${DATE}.tar.gz"
TARGET="${DEST%/}/$ARCHIVE"

# Создание архива так, чтобы внутри был сам каталог BASE
tar -C "$(dirname "$SRC")" -czf "$TARGET" "$BASE" 2>/dev/null
if [ $? -ne 0 ]; then
  echo "Ошибка: не удалось создать архив." >&2
  exit 4
fi

echo "Готово: создан архив $TARGET"
```

- **Файл настроен быть исполняемым:**

```sh
chmod +x backup.sh
```

### Объяснение ключевых команд

* `SRC="$1"` и `DEST="${2:-/backup}"` — первая переменная принимает обязательный аргумент (каталог для копирования), а вторая — путь для сохранения архива; если пользователь её не указал, берётся значение по умолчанию `/backup`.

* `if [ -z "$SRC" ]; then ... fi` — проверка: был ли вообще передан первый аргумент. Если нет — скрипт завершает работу с ошибкой.

* `if [ ! -d "$SRC" ]; then ... fi` — проверка: существует ли исходный каталог. Аналогично проверяется каталог назначения.

* `DATE=$(date +%Y-%m-%d)` — формирование строки с текущей датой в формате `ГГГГ-ММ-ДД`, которая используется в имени архива.

* `BASE=$(basename "$SRC")` — выделение имени каталога из полного пути (например, из `/home/user/important` получится `important`).

* `tar -C "$(dirname "$SRC")" -czf "$TARGET" "$BASE"` — ключевая команда, создающая архив:

  * `-C` — перейти в родительскую директорию исходной папки, чтобы в архив попал только сам каталог, а не полный путь.
  * `-czf` — создать архив в формате gzip (`c` — создать, `z` — сжатие gzip, `f` — имя файла берётся из аргумента).
  * `"$TARGET"` — путь и имя создаваемого архива.
  * `"$BASE"` — сама папка, которую нужно упаковать.

* `if [ $? -ne 0 ]; then ... fi` — проверка кода возврата последней команды. Если команда `tar` завершилась с ошибкой, выводится сообщение и скрипт завершает работу.

### 3. Проверка работы скрипта

Пошаговый запуск и проверка работы `backup.sh` показаны на скриншоте.

```sh
# Создаём каталог для лабораторной
mkdir ~/lab01
cd ~/lab01

# Создаём файл скрипта и делаем его исполняемым
nano backup.sh
chmod +x backup.sh

# Создаём каталог для хранения резервных копий и назначаем права
sudo mkdir -p /backup
sudo chown "$USER":"$USER" /backup

# Создаём тестовый каталог с файлом
mkdir -p ~/important/data
echo "тестовый файл $(date)" > ~/important/data/info.txt

# Запускаем скрипт для каталога ~/important
./backup.sh ~/important

# Проверяем, что архив создан
ls /backup

# Проверяем содержимое архива
tar -tzf /backup/important_$(date +%Y-%m-%d).tar.gz
```

![image](https://i.imgur.com/5nDLydh.png)

Скрипт `backup.sh` предназначен для создания резервной копии указанного каталога. При запуске указывается путь к исходной папке и, при необходимости, путь для сохранения архива (по умолчанию используется каталог `/backup`). В результате выполнения создаётся архив формата `tar.gz`, в имени которого автоматически проставляется текущая дата. На скриншоте показан процесс работы: был создан тестовый каталог `important` с файлом `info.txt`, после чего при запуске скрипта был сформирован архив `important_2025-09-12.tar.gz`. Проверка содержимого архива через команду `tar -tzf` подтвердила правильную структуру: внутри архива находится папка `important` с вложенной директорией `data` и файлом `info.txt`. Скрипт успешно отрабатывает задачу резервного копирования.
